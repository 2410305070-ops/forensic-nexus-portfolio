## 🚀 How to Run and View Each File

### 1. View Main Portfolio in Browser (Via Backend Server)
When the backend server is running (`npm start` inside `/backend`), visit:
- **Main Portfolio:** [http://localhost:5000/](http://localhost:5000/)

### 2. View 3D Scene or Shader Directly
You can open any file directly in Google Chrome, Microsoft Edge, or Firefox by right-clicking the `.html` file and selecting **"Open with..."** or double-clicking:
- **Main Portfolio:** `frontend/priya_saini_portfolio_forensic_science/index.html`
- **3D Interactive Scene:** `frontend/three.js/code.html`
- **Shader Effect:** `frontend/shader/code.html`
