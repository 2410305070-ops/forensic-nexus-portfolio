# 🔬 Forensic Science Nexus Portfolio

> An interactive, cyber-minimalist forensic science portfolio and digital laboratory showcase developed by **Priya Saini**.

---

## 🌟 Highlights & Features

- **Priya Saini Portfolio**: Case studies in *Digital Footprint Recovery*, *Fire Debris Analysis*, chain of custody, and forensic skill metrics.
- **Interactive 3D Visualizer**: Real-time Three.js scene featuring cyber-forensic particle grids and simulated evidence cubes.
- **Digital Lab Shader**: Fullscreen WebGL custom shader providing high-tech lab visual atmospheres.
- **Node.js & Express Backend**: Lightweight REST API and static asset server with live health-check endpoints.

## 🚀 Quick Start Guide

### 1. Run the Backend API & Frontend Server
```bash
cd backend
npm install
npm start
```
* The server will run on `http://localhost:5000`
* Visit `http://localhost:5000/` for the portfolio
* Visit `http://localhost:5000/api/test` for API verification

### 2. View Frontend Directly
Open `frontend/index.html` in any modern web browser.
